המאמן לאמירנט - התקנה כאפליקציה באנדרואיד

1. צור ריפו חדש ופומבי ב-GitHub (למשל amirnet).
2. העלה אליו את כל הקבצים מהתיקייה הזו (Add file > Upload files).
3. Settings > Pages > Source: Deploy from a branch > main / root > Save.
4. אחרי דקה-שתיים האפליקציה תהיה בכתובת https://<username>.github.io/amirnet/
5. בטלפון: פתח את הכתובת ב-Chrome > תפריט שלוש הנקודות > "התקנת אפליקציה".

קובץ APK (אופציונלי): pwabuilder.com > הדבק את הכתובת > Package for stores > Android.

האפליקציה עובדת בחינם ובלי אינטרנט. ההתקדמות נשמרת בטלפון; לגיבוי: היום > הגדרות > גיבוי.
